# GuideVault GitHub issue templates

Drop the `.github` folder into the root of the GuideVault repository.

Included templates:

- Bug report
- Feature request
- Metadata or import issue
- Performance issue
- Issue template config

Suggested path after copying:

```text
GuideVault/
  .github/
    ISSUE_TEMPLATE/
      bug_report.yml
      feature_request.yml
      metadata_import_issue.yml
      performance_issue.yml
      config.yml
```

The `config.yml` disables blank issues and points general questions toward GitHub Discussions. If Discussions are not enabled, either enable them in the repository settings or remove the `contact_links` section.
