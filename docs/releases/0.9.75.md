# Guidevault 0.9.75 - Metadata Source Lookups

## Added

- Split metadata lookup support:
  - Open Library lookup for guide/book metadata
  - IGDB lookup for game metadata
  - ESRB.org lookup for game rating metadata
- Comparison-based import workflow:
  - Review existing Guidevault values beside source values
  - Import all fields, empty fields only, or selected fields
  - Open Library cover preview is visual-only and cannot replace the Guidevault cover

## Improved

- Strategy guide details:
  - Game Title now drives the top detail page title
  - Strategy Guide Title appears under the Strategy Guide heading
  - Strategy Guide Title was removed from the guide overview/context card
- Platform normalization:
  - IGDB platform names are translated into Guidevault platform/icon naming
  - Added Sony, Microsoft, Sega, Windows, and MS-DOS normalization
  - Associated platform and preferred platform behavior was improved

## Fixed

- IGDB import now keeps the user on File & Metadata instead of switching back to Metadata.
- Search Open Library Metadata button styling was adjusted to better match the theme.
