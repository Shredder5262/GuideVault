# Reader

Guidevault includes a browser-based reader for scanned game literature.

## Reader modes

- Single page
- Two page spread
- Two pages adaptive

Adaptive mode is useful when one image contains two scanned pages.

## Reader controls

Guidevault supports:

- Previous / next page navigation
- Page slider
- Fullscreen
- Bookmarks
- Zoom
- Magnifier
- Background selection
- Reader shading and book-style presentation
- Transition preferences

## Reading profiles

Reading profiles can be applied at different levels.

Series-level preferences should take precedence over individual defaults when configured.

Typical profile values include:

- Page type
- Transition
- Background
- Zoom
- Brightness
- Fullscreen preference
