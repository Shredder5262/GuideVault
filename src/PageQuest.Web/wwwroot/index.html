Guidevault 0.9.30 - Library Scope Classification Fix Installed

Fixed 5

  • Fixed mixed Manual and Strategy Guide libraries fighting over the same indexed files when configured library folders overlap.
  • Added deterministic one-owner-per-file discovery so the most-specific configured library folder wins during scans.
  • Made explicit library types authoritative, while allowing Mixed libraries named Manuals, Strategy Guides, or Magazines to inherit the expected content type.
  • Fast rescans now repair cached items whose content type no longer matches the owning library.
  • Updated app version metadata for browser heartbeat and stable-image update checks.
Guidevault 0.9.29 - Platform Classification Expansion Installed

Fixed 5

  • Expanded fast-index platform detection for retro systems that were falling into Unsorted Manuals, including Atari, Amstrad, ColecoVision, Daphne/LaserDisc, Intellivision, Vectrex, Commodore, MSX, ZX Spectrum, Neo Geo, and Philips CD-i platforms.
  • Kept the fast scan path lightweight while improving folder/file-name inference for platform libraries.
  • Reduced manual misclassification caused by missing platform aliases rather than actual content-type errors.
  • Fast rescans now repair already-cached Unsorted items when improved path inference can classify them without reopening the archive.
  • Updated the app version metadata used by the browser heartbeat and stable-image update checks.
