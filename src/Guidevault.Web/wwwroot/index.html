Metadata Write-Back

Write the current GuideVault metadata from the database/override store back into selected source packages as Guidevault JSON.

CBZ files are updated in place. CBR and PDF sources use the existing package writer behavior and may create CBZ/ZIP metadata packages instead of modifying the original source.

Format Conversion

Show the current source format for the selected files and create converted copies beside the original packages.

Current Format Select files above to see their current formats.
Conversions are copy-first. GuideVault creates a new CBZ or PDF beside the source file and leaves the original untouched. PDF to CBZ needs a PDF rasterizer in the runtime. Run a rescan when you want the new copy indexed.

PDF to CBZ rasterizes PDF pages into numbered images when a runtime rasterizer is available. CBZ and PDF conversions are copy-first and never replace the original source file.

HA

Home Assistant

Publish GuideVault reader status into Home Assistant and allow Home Assistant automations to control the active GuideVault reader.

Create a Home Assistant long-lived access token, paste your Home Assistant base URL, then use the GuideVault command token in HA REST commands or automations.

Enable Home Assistant ConnectorTurn on state publishing and command endpoints.
Command endpoint: POST /api/home-assistant/command with Authorization: Bearer <GuideVault Command Token>. Supported actions include open, next_page, previous_page, set_page, zoom_in, zoom_out, set_zoom, set_display_mode, close_reader, and toggle_overlay. Open commands can include itemKind Manual, Strategy Guide, or Magazine, or use open_manual, open_strategy_guide, and open_magazine aliases.
